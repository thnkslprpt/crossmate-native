# Changelog

## 0.1.0+1 — Native beta source

- Rewrote Crossmate as a Flutter application with no WebView.
- Added an immutable Dart game model and independent legal-move engine.
- Added local two-player, three robot levels, and Firebase online rooms.
- Added all current piece mechanics, scoring, check/checkmate, and draw rules.
- Added four themes, first-launch rules, move review, responsive board UI, and native app icon.
- Added Ubuntu bootstrap, Android signing/build, Firebase configuration, macOS iOS preparation, tests, and GitHub Actions.
